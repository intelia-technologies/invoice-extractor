Privacy

Last updated 20 October 2026

Invoice Extractor is open-source software maintained by Intelia. This page covers the Chrome extension, the command-line tool, the MCP server, the Skill for AI agents, and this website.

The short version Invoice Extractor runs on your computer. We never receive your passwords, your invoices or your browsing. The only optional exception is profile sync, which you turn on yourself and point at a server you choose.

What stays on your computer

DataWhere it livesLeaves your computer?
Provider passwords and 2FA codesYour 1Password or Bitwarden vaultOnly to that provider's own login page
Provider cookies and sessionsChromeOnly to that provider
Invoice PDFsYour download folderNo
Download history, run progress, selected profileChrome storage and ~/.config/invoice-extractorNo
Saved profilesChrome storage and ~/.config/invoice-extractorOnly if you turn on profile sync

Credentials are read from your vault through the official op or bw command-line tool at the moment of login, and are never written anywhere else.

Optional profile sync

Profile sync keeps your saved profiles the same on several computers. It is off until you sign in to a sync service from the Profiles screen. Everything works without it.

What is sent

  • The names of your saved profiles.
  • Which providers are selected in each profile.
  • Each provider's configuration, such as a workspace URL or an account ID.

What is never sent

  • Cookies, provider logins and passwords.
  • Invoices, download history and run progress.
  • Which profile you currently have selected.
Choose a sync service you trust Workspace URLs and account IDs can be personal information. The extension talks to any server that implements the open profile-sync contract: you can use the service run by Intelia, or host your own.

Chrome permissions, and why

The extension asks for broad permissions because each provider's billing page is different. This is what each one is for.

Reading billing pages

<all_urls>, scripting, tabs, webNavigation and cookies let it open a provider's billing page, read the invoice table, and check that you are signed in to the right account.

Saving files

downloads saves the PDFs. debugger is used only to print receipt pages that have no PDF button; while it runs, Chrome shows a bar saying the extension is debugging the browser.

Talking to your vault

nativeMessaging lets the extension ask the small helper program installed on your computer for a login. storage and alarms keep your settings and run the optional sync in the background.

Install only the official release Because the extension can read the pages you open, a modified copy could do harm. Download it from this website or from the GitHub releases page, never from a third party.

This website

These pages are static. They set no cookies, run no analytics and load no third-party fonts or scripts. If you pick a language, that choice is kept in your browser's local storage under the key ie-lang and is never sent anywhere. The hosting provider may keep standard access logs. Downloads are served by GitHub under its own privacy policy.

Deleting your data

  1. Remove the extension in chrome://extensions. Chrome deletes its storage with it.
  2. Delete the folder the command-line tool uses:
$ rm -rf ~/.config/invoice-extractor

Your invoice PDFs stay in your download folder until you delete them. If you used profile sync, delete your account on that sync service as well.

Questions

Open an issue on GitHub, or contact Intelia. The code is public, so every statement on this page can be checked.
