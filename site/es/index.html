Todas tus facturas SaaS, archivadas antes de pedirlas.

Invoice Extractor entra en la página de facturación de cada proveedor con los accesos que ya guardas en 1Password o Bitwarden, localiza cada factura y la guarda en PDF en tu ordenador. Úsalo desde una extensión de Chrome o encárgaselo a tu agente de IA.

01 · Cómo funciona

Tu gestor de contraseñas ya tiene los accesos. Bonobot pone los clics.

A

Tu bóveda sigue siendo la fuente de verdad

Etiqueta tus accesos de facturación por cliente o empresa (#Acme) o guárdalos en una carpeta. Invoice Extractor los lee solo cuando los necesita, con la CLI oficial op o bw, códigos 2FA incluidos. No se copia nada a ningún servidor.

B

Una receta por proveedor, no un scraper por persona

Cada proveedor es una pequeña receta JSON declarativa: dónde está la página de facturación, cómo leer la tabla y cómo descargar. Cuando una web cambia, un solo arreglo en el catálogo lo arregla para todo el mundo.

C

PDF en tu disco, nunca repetidos

Los ficheros llegan a tu carpeta con un nombre coherente (fecha, proveedor, número e importe). Un historial local salta lo que ya tienes, así que puedes lanzarlo cada mes sin pensar.

02 · Dos formas de usarlo

Dale tú a empezar, o pídeselo a tu agente.

Para personas

Extensión de Chrome

Elige un perfil de cliente, marca los proveedores y pulsa empezar. La extensión inicia sesión con tu gestor de contraseñas, recorre el historial de facturación y lo descarga todo, lo mires o no.

  • Perfiles de cliente a partir de las etiquetas de tu bóveda
  • Modo grabar para crear un proveedor nuevo
  • Historial de descargas y nombres de fichero coherentes

Para agentes de IA

CLI · MCP server · Skill

Pídele a Claude Desktop, Claude Code o cualquier cliente MCP «descarga las facturas de este mes de Acme». Los agentes también pueden añadir un proveedor nuevo por su cuenta: inspeccionan la página de facturación, escriben la receta y la comprueban con una descarga real.

$ invoice-extractor profiles --sync-1p
✓ 3 perfiles · 41 accesos encontrados
$ invoice-extractor run --profile Acme --since 2026-09-01
✓ stripe 2 · github 1 · openai 1 · hetzner 3
$ invoice-extractor onboard --provider vercel
→ needs_creation · borrador de receta listo

04 · Instalar

Tres pasos y un doble clic.

Necesitas Google Chrome, Node.js 18+ (el instalador lo consigue por ti en Mac con Homebrew y en Windows) y 1Password o Bitwarden. El instalador se ocupa del resto: dependencias, el navegador de automatización, la CLI del gestor de contraseñas y Claude Desktop.

  1. Descarga invoice-extractor.zip y descomprímelo en un sitio definitivo, por ejemplo ~/Applications/invoice-extractor.
  2. Haz doble clic en install.command. Si macOS lo bloquea, clic derecho → Abrir. Elige 1Password o Bitwarden cuando te lo pregunte; los secretos se escriben en un diálogo nativo del sistema, nunca en un chat.
  3. Carga la extensión: abre chrome://extensions, activa el Modo de desarrollador, pulsa Cargar descomprimida y selecciona la carpeta descomprimida.
  1. Descarga invoice-extractor.zip y extráelo, por ejemplo en C:\Users\tu-usuario\invoice-extractor.
  2. Haz doble clic en install.bat. Si falta Node.js, lo instala con winget y te pide que lo vuelvas a ejecutar. Elige 1Password o Bitwarden; Windows Hello funciona con 1Password.
  3. Carga la extensión: abre chrome://extensions, activa el Modo de desarrollador, pulsa Cargar descomprimida y selecciona la carpeta extraída.
  1. Descarga y descomprime:

$ unzip invoice-extractor.zip -d ~/invoice-extractor && cd ~/invoice-extractor
  2. Ejecuta el instalador: bash install.command. Usa snap para instalar la CLI de 1Password o Bitwarden y abre un diálogo de zenity/kdialog para los secretos.
  3. Carga la extensión: abre chrome://extensions, activa el Modo de desarrollador, pulsa Cargar descomprimida y selecciona la carpeta.

¿Usas un agente de IA? Tras instalar, Claude Desktop ya tiene el servidor MCP invoice-extractor, y Claude Code, OMP y Antigravity reciben la Skill invoice-extractor. Solo tienes que pedirlo:

«Sincroniza mis proveedores desde 1Password y descarga las facturas del mes pasado de Acme.»

05 · Lo que no hace

Aburrido a propósito.

No guarda tus contraseñas

Las credenciales se leen de tu propia bóveda en el momento de iniciar sesión y no se escriben en ningún otro sitio.

No necesita una cuenta en la nube

Los perfiles y el historial viven en ~/.config/invoice-extractor. Hay una sincronización opcional de perfiles entre ordenadores, pero todo funciona sin ella.

No llama a casa

El único tráfico de red es tu navegador hablando con tus proveedores. Lee el código: está todo en GitHub.
