01 · How it works

Your vault already knows the logins. Bonobot does the clicking.

A

Your vault stays the source of truth

Tag your billing logins by client or company (#Acme) or keep them in a folder. Invoice Extractor reads them when it needs them through the official op or bw CLI, live 2FA codes included. Nothing is copied to a server.

B

One recipe per provider, not one scraper per person

Each provider is a small declarative JSON recipe: where the billing page lives, how to read the table, how to download. When a site changes, one fix in the catalog fixes it for everybody.

C

PDFs on your disk, never twice

Files land in your folder with a consistent name (date, provider, number, amount). A local history skips what you already have, so you can run it every month without thinking.

02 · Two ways to use it

Press start yourself, or ask your agent.

For humans

Chrome extension

Pick a client profile, tick the providers, press start. The extension signs in with your password manager, walks through the billing history and downloads everything, whether you watch or not.

  • Client profiles from your vault tags
  • Record mode to create a new provider
  • Download history and consistent file names

For AI agents

CLI · MCP server · Skill

Ask Claude Desktop, Claude Code or any MCP client “download this month's invoices for Acme”. Agents can also add a new provider on their own: they inspect the billing page, write the recipe and check it with one real download.

$ invoice-extractor profiles --sync-1p
✓ 3 profiles · 41 logins matched
$ invoice-extractor run --profile Acme --since 2026-09-01
✓ stripe 2 · github 1 · openai 1 · hetzner 3
$ invoice-extractor onboard --provider vercel
→ needs_creation · recipe draft ready

04 · Install

Three steps, one double-click.

You need Google Chrome, Node.js 18+ (the installer gets it for you on Mac with Homebrew and on Windows) and 1Password or Bitwarden. The installer takes care of the rest: dependencies, the automation browser, the password-manager CLI and Claude Desktop.

  1. Download invoice-extractor.zip and unzip it somewhere permanent, e.g. ~/Applications/invoice-extractor.
  2. Double-click install.command. If macOS blocks it, right-click → Open. Choose 1Password or Bitwarden when asked; secrets go into a native system dialog, never into a chat.
  3. Load the extension: open chrome://extensions, turn on Developer mode, click Load unpacked and select the unzipped folder.

  2. Double-click install.bat. If Node.js is missing it installs it with winget and asks you to run it again. Choose 1Password or Bitwarden; Windows Hello works with 1Password.
  3. Load the extension: open chrome://extensions, turn on Developer mode, click Load unpacked and select the extracted folder.

05 · What it does not do

Boring on purpose.

It does not store your passwords

Credentials are read from your own vault at the moment of login and never written anywhere else.

It does not need a cloud account

Profiles and history live in ~/.config/invoice-extractor. Optional profile sync between computers exists, but everything works without it.

It does not phone home

The only network traffic is your browser talking to your providers. Read the code: it is all on GitHub.
