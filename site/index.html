Every invoice, filed in one run.

Invoice Extractor signs into each provider's billing page with the logins you already keep in 1Password or Bitwarden, finds every invoice and saves it as a named PDF on your disk. Do it yourself from the Chrome extension, or ask your AI assistant to do it for you.

Public beta, open source (MIT). For now you install it by hand from this download, not from the Chrome Web Store, and you can read every line of what you install.

Your passwords never reach us or your AI.

Everything runs on your computer. At sign-in, Invoice Extractor asks 1Password or Bitwarden for the login and types it into the billing page, in a browser on your computer: your Chrome with the extension, or a separate automation browser when an assistant runs it.

Your assistant only asks for a run and reads the result. Passwords and 2FA codes are not part of any result it receives. When setup needs a vault token, a system dialog asks for it, so it never passes through the chat.

Two ways to run it. Both on your computer.

Ask your AI assistant, or do it yourself from the Chrome extension. Either way, an engine on your computer signs in, reads the billing pages and saves the PDFs.

Ask your AI

Connect it to Claude, Codex, Cursor or any assistant that speaks MCP, the standard way AI apps plug in an outside tool. Then ask in your own words:

The assistant starts the run on your computer and gets back only the result: which PDFs were saved and where, and which providers couldn't finish. If a provider asks for a code sent by email or SMS, it is listed as not finished: run that one yourself from the extension, which waits while you type the code on the provider's own page. The code never goes into the chat.

It also saves tokens. During a run the assistant doesn't open or read the billing pages; the engine on your computer does. The assistant spends tokens on your request and on the list of files saved, not on the pages themselves.

Do it yourself

Open the Chrome extension, pick a profile and press Start Download. It works in your own Chrome, on the sessions you already have, signs in with 1Password or Bitwarden when needed, and waits for you only when a login needs a person.

Three steps, one double-click.

You need Google Chrome, Node.js 18+ (the installer gets it for you on Mac with Homebrew and on Windows) and 1Password or Bitwarden. The installer takes care of the rest: dependencies, the automation browser, the password-manager CLI and Claude Desktop.

  1. Download invoice-extractor.zip and unzip it somewhere permanent, e.g. ~/Applications/invoice-extractor.
  2. Double-click install.command. If macOS blocks it, right-click → Open. Choose 1Password or Bitwarden when asked; secrets go into a native system dialog, never into a chat.
  3. Load the extension: open chrome://extensions, turn on Developer mode, click Load unpacked and select the unzipped folder. Leave the folder where it is: Chrome runs the extension from it.

What you're about to allow

The extension asks for broad permissions because each provider's billing page is different. The two that stand out:

Access to every site <all_urls>
To open a provider's billing page, read the invoice table and check that you are signed in to the right account.
The debugger debugger
Only to print receipt pages that have no PDF button. While it runs, Chrome shows a bar saying the extension is debugging the browser.

Install only from this site or GitHub Releases. Because the extension can read the pages you open, a modified copy could do harm.
